A TINY THING FOR YOU

Open index.html in a browser to preview. Each main tile opens a separate HTML page.

Pages:
- index.html: home with rose bouquet and interactive teddy bear
- bloom.html: add roses and sparkles
- notes.html: little reminders
- letter.html: short, shy note
- music.html: visible YouTube player for a 30-second snippet of “You're Here That's the Thing” by beabadoobee, plus direct YouTube and Spotify search links
- cinna.html: cute Cinnamoroll-inspired ending

Publish on GitHub Pages:
1. Unzip this folder.
2. Upload all files inside this folder to the root of your repository.
3. Make sure index.html is directly at the repository root.
4. Go to Settings > Pages and enable publishing from your chosen branch.

Music note: the player is now visible because embedded players need a usable viewport. It uses YouTube's official IFrame Player API and pauses 30 seconds after playback begins. YouTube may still block embedding for a particular video or browser. If that happens, use the direct YouTube link or Spotify search link shown on the page. Spotify search opens the track search, not guaranteed playback of a preview.
